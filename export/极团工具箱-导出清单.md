# 极团工具箱｜设计导出清单

已确认的 Figma 文件：

- [极团工具箱｜小程序 UI 方案](https://www.figma.com/design/znpYuQvM7Gwyvw8W8InmSw/极团工具箱｜小程序-UI-方案?node-id=0-1)

本地导出资产：

- `极团工具箱-UI-完整导出.svg`：首页、图片压缩、图片转文字、图片转 PDF 的开发交接总览。
- `极团工具箱-设计规范.svg`：颜色、字体、间距、按钮、广告位规范。
- `极团工具箱-状态页-无滤镜.svg`：压缩工具空状态、处理中、完成、失败状态板。

设计基准：

- 画布：390 × 844，适配原生微信小程序。
- 主色：`#2F80ED`；深色文字：`#15233B`；成功色：`#22C55E`。
- 卡片圆角：16px；浅色背景 + 轻阴影；结果页和首页底部保留广告位。
- 导出源保留为 SVG，便于继续在 Figma 或矢量工具中编辑。

说明：Figma 画布已保留为可编辑源文件；本地 SVG 是当前确认版的开发交接导出，代码中的页面按同一套 token 和信息架构实现。
