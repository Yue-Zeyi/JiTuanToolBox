# 极团工具箱

原生微信小程序，当前收录 60 个工具，分为图文处理、数学计算、信息查询、生活娱乐。工具以本地处理为主，操作记录和收藏保存在用户本机，首页常用工具按全站累计点击量动态展示。

当前版本包含图片压缩、尺寸修改、图片拆块、图片拼接、图片转 PDF、图片加水印、图片隐私遮挡、文本清洗、文字比对、JSON 格式化、房贷与 BMI 计算、单位换算、时间工具、随机工具以及本地生活优惠入口等功能。新增工具会先在全部工具页按分类收录，再根据使用数据参与首页推荐。

## 开发与部署

1. 微信开发者工具导入项目根目录，使用 `project.config.json` 中的项目配置。
2. 运行参数在 `config/runtime.js`，包含云环境 ID、检测函数名称和超时设置。
3. 云函数位于 `cloudfunctions/`，包含内容安全、检测回调、网络信息和工具热度统计。内容安全部署步骤见 `docs/微信内容安全2.0部署说明.md`，回调 Token 等敏感值仅在云端环境变量配置，不提交仓库。
4. 日常直接修改本目录，由开发者工具编译预览。

### 聚推客联盟插件

1. 在微信公众平台为当前小程序添加“电影票服务”插件（提供方 AppID：`wx89752980e795bfde`）、“外卖美食团购”插件（提供方 AppID：`wx5c787b48e6a02a51`）和“大牌点餐”插件（提供方 AppID：`wx6c999744b6d125ef`）。
2. 在聚推客联盟后台“开发”页面取得联盟 ID，将其填写到 `config/runtime.js` 的 `jutuikePubId`。
3. 项目当前分别按插件开发文档声明版本 `1.1.7`、`1.2.5` 与 `1.5.6`，上线前应在插件更新记录中复核最新可用版本。

## 数据处理

图片压缩、尺寸修改、拆块、拼接、PDF 生成、水印和图片隐私遮挡等图片处理在本机完成；选图后需先通过微信云端内容安全检测，检测完成后删除云端临时文件。隐私遮挡的操作记录只保留遮挡后的结果，不保存原图。文本清洗、AA 分账和其他计算类工具默认在本机运行，不上传用户输入。公网网络信息查询和全站工具热度统计使用云函数，其余工具以各页面底部的隐私处理说明为准。

收藏最多保留 30 个工具，操作记录最多保留 20 条；超出上限时自动删除最早记录及其本地临时文件。

## 目录说明

- `pages/`、`custom-tab-bar/`：页面与底部导航
- `services/`、`utils/`：处理服务、算法与本地依赖
- `package-text/`、`package-calendar/`、`package-calc/`、`package-query/`、`package-life/`：按功能拆分的工具分包
- `package-movie/`、`package-deals/`、`package-dining/`：按插件拆分的跳转分包，避免插件资源进入主包
- `assets/`：图标、品牌和分享素材
- `cloudfunctions/`：内容安全、回调、网络信息与工具热度云函数
- `docs/`：部署与依赖说明

保留开源依赖的许可证。开发者个人配置、密钥、依赖安装目录、临时产物、产品方案和设计资料由 `.gitignore` 排除。
