# 极团工具箱

原生微信小程序，当前收录 30 个工具，分为图文处理、数学计算、信息查询、生活娱乐。操作记录保存在用户本机。

## 开发与部署

1. 微信开发者工具导入项目根目录，使用 `project.config.json` 中的项目配置。
2. 运行参数在 `config/runtime.js`，包含云环境 ID、检测函数名称和超时设置。
3. 云函数位于 `cloudfunctions/`，部署步骤见 `docs/微信内容安全2.0部署说明.md`。回调 Token 等敏感值仅在云端环境变量配置，不提交仓库。
4. 日常直接修改本目录，由开发者工具编译预览。

## 数据处理

图片压缩、尺寸修改、拆块、拼接、PDF 生成和水印处理在本机完成；选图后需先通过微信云端内容安全检测。公网 IP 查询依赖云函数，其余工具以各页面的处理说明为准。

`useMockServices` 当前为 `true`，OCR 是预留能力，未列入正式工具目录，其模拟结果不代表真实识别结果。

## 目录说明

- `pages/`、`custom-tab-bar/`：页面与底部导航
- `services/`、`utils/`：处理服务、算法与本地依赖
- `package-text/`：繁简转换分包
- `assets/`：图标、品牌和分享素材
- `cloudfunctions/`：内容安全、回调与 IP 查询云函数
- `docs/`：部署和设计文档
- `export/`：已确认的设计导出

保留开源依赖的许可证。开发者个人配置、密钥、依赖安装目录和临时产物由 `.gitignore` 排除。
